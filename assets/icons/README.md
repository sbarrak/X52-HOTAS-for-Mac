# App icons used so far

Every app icon artwork the app has shipped with, named `<first version> <name>.png`. The icon in use is
`assets/AppIcon.png` (`tools/make_icon.swift` builds the macOS icon from it). When the icon changes, add the new
artwork here too, so earlier icons are kept.

- `1.6.3 Hardware Link.png`: the stick linked to an aircraft (from 1.6.3). Before 1.6.3 the icon was drawn in code.
